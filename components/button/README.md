# Button — ODD Core

Primary, secondary and native disabled buttons using the shared Core stylesheet. Open index.html from this checkout; it references the authoritative ../../odd-core.css. No JavaScript or external service is required. Buttons retain native keyboard semantics and visible focus styles.

Version 1.0.1 is a migration candidate that uses the current camelCase Core styling and MIT license requested in the migration brief. The historical 1.0.0 archive is retained unchanged in private migration evidence with its original license. It is not overwritten or reissued here.

MIT: see the repository LICENSE. The preview has been checked at 360px and 1280px in Chromium, including keyboard focus, disabled state, transparent background and horizontal overflow. Broader browser/accessibility checks remain separate from these smoke tests. No production release has been published.
